# Architecture

## Purpose

This section contains all technical architecture decisions for the HRMS platform.

The architecture documents explain how the system will be designed and implemented.

These documents are intended for architects, developers, and AI coding assistants (Claude).

---

## Document Order

The documents in this section should be read in the following order:

1. Architecture Overview
2. Technical Design Document (TDD)
3. Architecture Decision Records (ADR)
4. System Diagrams
5. Deployment Architecture

---

## Rules

- Architecture decisions must be approved before implementation.
- Claude must follow these documents during development.
- Any architecture changes must be documented before code changes.
